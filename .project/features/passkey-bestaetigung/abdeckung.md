# Abdeckung: passkey-bestaetigung (#2225)

Risiko kritisch. Grünbar entfällt (Feature mit Fakes bzw. echter Kryptoprüfung über `tests/Support/PasskeyGeraet.php`; der Coder macht die Tests grün). Ausführen (Host-Ordner): `php artisan test --compact packages/userauth/tests/Feature/Passkey packages/userauth/tests/Feature/SocialLogin` und `node --test packages/userauth/tests/js/passkey-bestaetigung.test.mjs`.
